# Decision Engine (Hybrid Model)

This project contains Python scripts for a Hybrid Decision System using YOLO models (both Grayscale and RGB).

## Features
- Inspecting YOLO models (`best-gray.pt` and `best-rgb.pt`)
- Comparing different color spaces (BGR vs RGB vs Grayscale)
- Debugging inference results

## Requirements
- Python 3
- PyTorch
- OpenCV (`cv2`)
- Ultralytics (`yolo`)
- NumPy
